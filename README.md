# Энтропия

Браузерное фортепиано с декором из мха.

## Запуск

Откройте `index.html` или `html/index.html` в браузере. Включите красный тумблер для запуска звука. Зелёная кнопка сбрасывает настройки звука.

Белые клавиши: Z X C V B N M и Q W E R T Y U. Чёрные: S D G H J и 2 3 5 6 7. Физические клавиши работают независимо от раскладки.

Крутилки регулируются вертикальным перетаскиванием или стрелками после выбора. Настройки сохраняются локально в браузере.

## Структура

- `html/` — интерфейс.
- `css/` — оформление.
- `js/` — управление и звуковой движок.
- `assets/images/` — изображения и исходники.
- `assets/audio/piano/` — локальные записи фортепиано и сведения об авторстве.

Для загрузки Tone.js 14.8.49 и Google Fonts требуется интернет. Семплы фортепиано загружаются из локальных ассетов, включая запуск с диска.

## Два канала

Нижняя октава C3–B3 направлена в канал I с панорамой −0,3; верхняя C4–B4 — в канал II с панорамой +0,3. У каждого канала собственные настройки тембра, ADSR, биткрашера, дисторшна, фильтра, задержки и реверберации. Кнопки I и II выбирают канал для настройки. Оба канала звучат одновременно; общими остаются только мастер-выход, лимитер и осциллограф.
